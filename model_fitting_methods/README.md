# Core concepts

Must be addressed irrespective of method chosen

- [Introduction to the Concept of Likelihood and Its Applications](https://journals.sagepub.com/doi/10.1177/2515245917744314)
- _Key considerations for model fitting and calibration_: [Choices and trade-offs in inference with infectious disease models](https://www.sciencedirect.com/science/article/pii/S1755436519300441?via%3Dihub)

## Least Squares Method

- _Key tutorial on the least squares method_: [Fitting dynamic models to epidemic outbreaks with quantified uncertainty: A primer for parameter uncertainty, identifiability, and forecasts](https://www.sciencedirect.com/science/article/pii/S2468042717300234)
- [Fitting Epidemic Models to Data by James Holland Jones](https://web.stanford.edu/class/earthsys214/notes/fit.html)

## Maximum Likelihood Estimation (MLE)

- [Fitting Epidemic Models to Data by James Holland Jones](https://web.stanford.edu/class/earthsys214/notes/fit.html)
- _R tutorial on MLE_: [Estimating model parameters by maximum likelihood](https://daphnia.ecology.uga.edu/drakelab/wp-content/uploads/2014/07/likelihood.pdf)
